## candidate.2 磁盘空间修复

用户截图显示 D 盘可用 280.9 GB，却提示需要 146 MiB 而空间不足。检查 NSIS 3.10 随附 System 文档及插件源码，确认 Int64Op 参数应为 ARG1 OP ARG2；旧安装器的两个比较均将运算符放到最后。已修正目标盘及 TEMP 检查，添加实际字节数日志、非法参数构建阻断及原始错误注入回归测试。此修复已重新编译并核对安装器载荷；当前没有 Windows 环境，目标机安装重试仍待验证。
